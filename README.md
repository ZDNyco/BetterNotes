# BetterNotes
Online (annoying)Note System


If you are a creative person, is really normal having ideas in the middle of another activity on a daily basis. You tend to write that down somewhere and then forget about it. This app promises to give a solution to that.

Save your notes for later, get notified and reminded to do them.

We would notify you in your pc every time you start it (this option can be disabled, but, what's the point of the app if you do so? it's meant to be annoying.). The app will opne automatically and show the most urgent notes, so if you planned to game or do whatever you will remember you have something to do, is up to you if you still decided to do it later.
